# Theropod skin batch

Procedurally painted skins with true per-face UV islands for the theropod
roster, generated by `scripts/build_skins.py` on top of `scripts/skin_studio.py`.
Only new files were created: the source models, textures and scripts were not
modified.

pixel, face count = cubes x 6, atlas fits.

## Where the results are

Each creature has a new `skin/` folder next to its model:

```
Creatures/<Name>/skin/
  skin.png                     painted atlas (256 or 512)
  <identifier>.geo.json        geometry with the new per-face UVs
  <Name>_Textured.bbmodel      Blockbench project with the texture embedded
  skin_report.json             atlas stats, part census, checks
  previews/
    side.png
    three_quarter.png
    front.png
    uv_check.png
    texture_atlas.png
```

Batch artefacts:

```
Creatures/Collection/skins/
  overview.png                 contact sheet of all three-quarter previews
  report.json                  full per-creature reports + failures
```

- Open the textured Blockbench project to inspect a skin; do **not** import the
  atlas into the old `*_GeckoLib.bbmodel`, its palette UVs still point at the
  old 64x8 sheet.
- Regenerate one species with `python scripts/build_skins.py --species Tyranosaur`.
- List the roster with `python scripts/build_skins.py --list`.

## Known tuning items for the next pass

- Dilophosaur frill: currently uses the horn/amber accent; consider a banded
  frill motif.
- Spinosaurus sail: add a dedicated sail pattern (stripes/spines) instead of
  the body hide.
- Therezinosaur beak and giant claws, Velociraptor/Raptor feathers: paint
  feather rows and beak keratin explicitly.
- Allosaurus: 20% atlas usage at 512; a better packer or a 384 atlas would be
  cheaper.
- Head details (lip line, teeth, eye) are placed from surface profiles; they
  read best on the large predators and should be spot-checked per species.
